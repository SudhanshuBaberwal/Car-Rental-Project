# 🚗 Car Rental System – MERN Stack

A full-stack Car Rental Web Application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
This platform allows users to browse available cars, book rentals, and manage bookings, while admins can manage cars and rental records.

---

## 📌 Project Overview

The Car Rental System simplifies online car booking with a clean and user-friendly interface.

### Key Highlights:
- Full-stack MERN implementation
- RESTful API architecture
- JWT-based authentication
- Role-based authorization (User/Admin)
- MongoDB database integration

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- Bootstrap / Tailwind CSS

### Backend
- Node.js
- Express.js
- JWT (JSON Web Token)
- bcrypt.js

### Database
- MongoDB
- Mongoose

---

## ✨ Features

### 👤 User Features
- User Registration & Login
- Secure JWT Authentication
- Browse available cars
- View detailed car information
- Book car with selected dates
- View booking history
- Cancel bookings

### 🛠️ Admin Features
- Add new cars
- Update car details
- Delete cars
- View all bookings
- Manage car availability
